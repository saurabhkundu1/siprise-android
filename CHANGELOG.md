# Changelog

## [1.5.0] - Unreleased

### Improved

- Format recent sip times using the device's 12- or 24-hour preference.

## [1.4.0] - Unreleased

### Added

- Choose local reminder hours, including overnight schedules; 9 a.m.–9 p.m. remains the default.

## [1.3.0] - Unreleased

### Added

- Add a 30-minute snooze action to hydration reminders.

## [1.2.0] - Unreleased

### Changed

- Pause daytime reminders after the daily goal is met, then resume at 9 a.m. the next day.

## [1.1.0] - Unreleased

### Added

- Home-screen widget for today's progress and one-tap quick logging.
- Spoken progress and quick-log descriptions for screen-reader users.
- Choose the home-screen widget's quick-log amount from 50–1,000 ml in 50 ml steps; the default remains 250 ml.

## [1.0.0] - Unreleased

### Added

- One-tap quick logging and custom water amounts, with undo for the latest entry.
- Daily goals, a seven-day progress chart, and recent intake history.
- Optional daytime reminders scheduled on-device.
- Offline storage with no internet permission or network calls.
